# UAE PEPPOL PINT AE Interactive Learning Platform

Production-grade Next.js 14 application for visually learning UAE PEPPOL PINT AE e-invoicing architecture, flows, validation, and integration patterns.

## Stack
- Next.js 14 App Router
- TypeScript (strict)
- Tailwind CSS
- Framer Motion
- Zustand
- Recharts
- Lucide React Icons
- Mermaid.js
- React Flow
- Prism.js

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Deployment
Deploy directly to Vercel with zero configuration.

## Environment
No required environment variables for local simulation mode.
